1. Service Description

Renewal Desk is a SaaS platform that helps gym owners and fitness businesses:

  • Track gym member subscriptions and expiry dates
  • Send automated WhatsApp renewal reminders with payment QR codes via the Meta WhatsApp Business Cloud API
  • Control biometric door access (compatible eSSL/ZKTeco devices) based on membership status
  • Manage multiple gym locations from a single dashboard
  • Use an AI receptionist for automated WhatsApp responses (where enabled)
  • Import member data via CSV

The service is available as a web application and an Android application (package: online.revorax.renewaldesk).
